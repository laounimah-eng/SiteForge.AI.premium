# SiteForge AI — v4 Lunar Electric Purple

Premium AI website builder with:

- Lunar / electric-purple interface
- AI website generation via OpenRouter
- Natural-language editing / AI Copilot
- Live desktop, tablet and mobile preview
- Production quality audit
- SEO metadata optimizer
- Templates and project workspace
- Design Studio with palette + typography guidance
- Honest placeholder / anti-fake-data generation rules
- HTML export
- Publish/deployment guidance
- Local browser project history

## Run

```bash
npm install
npm start
```

Set these server-side environment variables:

- `OPENROUTER_API_KEY`
- `OPENROUTER_MODEL` (optional, default `openrouter/free`)
- `SITEFORGE_PUBLIC_URL` (optional)

Never put the API key in frontend code or commit it to GitHub.
